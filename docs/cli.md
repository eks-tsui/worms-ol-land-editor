# 命令行参考

命令行入口与 WinForms 界面共用一个 Windows 可执行文件 `WormsLandEditor.exe`。不传参数会打开图形界面；传入未知命令、缺少参数或额外参数会报告错误并返回非零退出码，不会意外打开界面。

本页列出全部已实现入口。高级诊断和格式修改命令不等同于完整兼容性保证；尤其涉及资源包重写时，应先在自己有权使用的数据副本上验证。构建、自动测试、Windows 界面和真实素材的验证范围应分别确认，不能互相替代。

## 调用规则

- `WormsLandEditor.exe --help`：显示随界面语言切换的帮助。默认语言由系统语言决定，英文为回退语言，提供简体中文资源。
- 命令名称区分大小写，参数按列出的顺序提供。`[...]` 表示可选项，不要输入方括号；`...` 表示可继续添加路径。
- 含空格的路径必须用引号包围。布尔值只能使用列出的英文小写值；导入类型不区分大小写。
- 退出码：`0` 成功，`1` 执行或文件处理失败，`2` 命令或参数错误。
- 正常报告写入标准输出，错误和写入风险提示写入标准错误。写入命令成功时也会产生标准错误提示，不能仅凭标准错误非空判断失败，应检查退出码。
- 这是 Windows GUI 子系统程序。脚本应等待进程退出并显式收集标准输出和标准错误；图形界面执行 PNG 转换也使用这种方式。不要把没有看到终端文本误判为转换成功。

## 写入约定与风险

所有输出命令均可能直接覆盖已有文件，不询问、不创建备份。执行前会列出目标路径。指定与输入相同的输出路径就会原位覆盖，请自行选择新目录或先备份。

- DAT 保存会限制地形调色板，可能改变量化颜色；“读写往返”不代表字节无损。
- 资源包保存的文件名固定为 `Level.Dir`。对已有资源包的修改写到所给文件所在目录的 `Level.Dir`，而不是任意自定义文件名。
- `Level.Dir` 保存会重新序列化、规范化 SPR 资源，不保证未选择资源的字节原样不变。需要有效的已有资源目录索引，不能从零创建任意条目。
- 多文件写入不具备事务性。如果第二个文件或写后验证失败，前面的文件可能已经写入；错误报告不能视为“没有任何变化”。重试前先检查目标文件。
- DAT 和普通 PNG/GIF 输出的父目录应事先存在；资源目录保存和诊断图导出会创建目标目录。
- 对不支持的资源目录项或异常素材没有“自动修复并保真”的承诺。请保留原始数据。

## 地图读取、创建和导出

### `--inspect <地图.dat> [Level.Dir]`

只读。打印地图尺寸、封闭标志、两组出生点数量、地形调色板和遮罩尺寸。可选读取 `Level.Dir` 的目录范围与条目名称。

### `--frompng <输入.png> <输出.dat>`

写入一个 DAT。PNG 必须为 **1920×696**；完全透明像素为空洞，任何非零 alpha 的像素都是实体，不按亮度或黑色识别空洞。碰撞和辅助遮罩同步生成，预览遮罩清空。

此命令**不生成 Level.Dir、不添加出生点，也不设置最终编号的地图资源路径**。名称初始来自 PNG 文件名，后续应在图形界面设置有效地图编号、出生点和配套资源并保存。地形保存最多保留96个非透明调色板颜色；不是无损真彩色转换。

### `--replacepng <输入.dat> <输入.png> <输出.dat>`

写入一个 DAT。PNG 尺寸与透明规则同上；替换地形并重建碰撞/辅助遮罩、清空预览遮罩，保留其他地图字段和出生点。保留的出生点未必仍适合新地形，需要检查。

这两个 PNG 入口的参数顺序也是图形界面转换子进程协议，保持兼容。

### `--exportpng <输入.dat> <输出.png>`

写入一张 PNG。将地形调色板索引0导出为透明，可用于后续编辑和再导入；不恢复之前量化丢失的颜色或连续 alpha。

### `--roundtrip <输入.dat> <输出.dat>`

写入一个 DAT，并重新加载输出验证可读取性。保存可能限制调色板，不能用作逐字节无损测试。

### `--repair-spawns <输入.dat> <输出.dat>`

写入一个 DAT。规范化并尝试补充出生点，然后打印出生点诊断报告。算法不保证所有地形都能获得至少12个有效点。

### `--normalize-masks <输入.dat> <输出.dat>`

写入一个 DAT。根据地形非零索引重建碰撞/辅助遮罩，清空预览遮罩。

### `--set-closed-map <输入.dat> <输出.dat> <true|false|1|0|yes|no>`

写入一个 DAT。修改封闭地图标志；值必须为上述小写形式。

## 资源读取、替换和导出

### `--spr-info <Level.Dir> <资源.spr>`

只读。输出 SPR 标志、调色板、画布头字段、帧数和像素统计；列出最多前8帧的边界信息。

### `--export-resource <Level.Dir> <资源名称> <输出路径>`

写入一张 PNG 或一个 GIF。单帧编码为 PNG，多帧编码为 GIF，**编码由帧数决定，不由输出后缀决定**。多帧请指定 `.gif` 后缀。保留 SPR 画布，GIF 固定120毫秒/帧，不保留原始动画时序。

### `--export-resource-frame <Level.Dir> <资源名称> <输出.png>`

写入一张 PNG，仅导出首帧，保留 SPR 画布。没有帧序号参数。

### `--replace-resource <Level.Dir> <资源名称> <替换.png|替换.gif>`

重写目标文件所在目录的 `Level.Dir`。只能替换已有条目：

- IMG 只接受 PNG，必须匹配原宽高，可能重新量化调色板。
- SPR 接受 PNG 或 GIF，保留原调色板并映射新颜色。PNG 将整段动画替换成单帧，不是只替换第一帧；GIF 使用所有帧，最多255帧。
- `back.spr` 的输入宽度必须为640；`debris.spr` 宽高均不能超过80；其他 SPR 按现有帧边界校验尺寸。
- IMG/SPR 资源的透明阈值与主地图不同：alpha 小于96视为透明。

写后报告按实际 IMG/SPR 类型选择，不会把成功替换的 IMG 再按 SPR 解析。

### `--copy-resource <源-Level.Dir> <资源名称> <目标-Level.Dir>`

读取源包已有资源，替换目标同名已有资源，再规范化并重写目标目录的 `Level.Dir`。不是增加新目录项。源包不修改。

### `--normalize-level-dir <Level.Dir>`

规范化资源格式并重写原目录的 `Level.Dir`。可能改变多个 SPR 资源，不只是格式报告。

### `--set-spr-canvas <Level.Dir> <资源.spr> <宽> <高>`

高级修改命令。宽高是0–65535的整数，修改 SPR 的画布头字段并重写 `Level.Dir`，**不会重采样像素或改变帧边界**。0表示写入零字段，不是生成有效零尺寸图像；实际显示尺寸仍可能由帧边界和资源规范化决定。保存 `debris.spr` 时其头字段可能被规范化扩大。

### `--remap-land-palette <输入.dat> <输出.dat> <Level.Dir> [旧waterDir参数]`

高级修改命令。建立最多96色的地形调色板，对地图和 `Level.Dir` 中相关资源进行重映射；写入输出 DAT，并在资源包原目录重写 `Level.Dir`。这两个写入不具备事务性。

旧版本要求但并未使用 `waterDir`。现在推荐省略；为兼容已有调用，仍接受第四个路径参数，并明确打印“忽略、不修改水资源”的提示。传入此参数不会读取水目录、调整水资源或更新地图水资源路径。

## 兼容地图导入

### `--import-legacy <auto|underwater|wa|armageddon|wwp> <源路径> <模板Data目录> <输出.dat> <输出Level目录> [地图编号 [水资源路径]]`

读取已实现适配范围内的地图素材，写入 DAT 和输出目录的 `Level.Dir`。

- `auto` 按源路径和内容检测；`wa` 与 `armageddon` 为同一适配类型。未知类型明确报参数错误，不会默默按 `wwp` 处理。
- 保持原有5参数协议兼容：省略编号时使用 **45**；省略水资源路径时使用 **data\water\Red**。使用默认值会显示提示，输出文件名不会自动设置内部资源路径。
- 可追加地图编号，范围1–999；再追加水资源路径。水资源路径是写入地图内部的1–127字符 ASCII 资源路径，而不是要求将任意操作系统绝对路径写入地图。必须与自己的资源布局相符。
- 使用显式编号时，地图内部路径为 `data\mfx\TmapNN`，不足两位补零。输出目录可以另选，但之后要正确放置配套资源。
- 模板 Data 目录必须具备可用的 `Mfx/Tmap01/Level.Dir`。源素材需符合已实现适配器的目录结构；同扩展名不代表任意文件均可导入。
- WAM 需配套同名 IMG；主地图 IMG 必须为1920×696。只有主题目录且找不到地图时可能得到空主地图。
- 仅尝试迁移 `gradient.img`、`back.spr`、`debris.spr`、`soil.img`、`grass.img`；缺失或空资源继续使用模板，并进行调色板转换。不是完整复制源目录，也不保证像素或动画时序保真。
- DAT 和 Level.Dir 先后写入，后者失败不会撤销已写的 DAT。

## 高级诊断

以下入口保留用于检查素材，不应当作一般工作流或兼容性承诺。除最后一项外均只读。

### `--palette-report <地图.dat|Level.Dir> ...`

输出图像或资源的调色板、使用索引和字节数。某个资源解析失败时继续报告该包的剩余资源，但会在标准错误记录失败，并以退出码1结束；报告可能不完整。

### `--palette-union <地图.dat|Level.Dir> ...`

统计输入调色板的不同 RGB 颜色数量，包含未被像素使用的调色板颜色；不是对最终渲染画面做颜色统计。

### `--points-report <地图.dat>`

输出主出生点位置及碰撞、下方实体、净空和邻域统计。辅助出生点只在摘要中显示数量。

### `--mask-terrain-report <地图.dat> ...`

统计地形与碰撞遮罩的组合、辅助遮罩差异、预览非零位和开头字节；同时输出按字节内反转位序计算的诊断统计，不会修改文件。

### `--slot-conflicts <地图.dat> <Level.Dir>`

按调色板槽位比较地图与资源颜色，报告冲突数量和第一个冲突槽位；不自动修复。

### `--legacy-spr-info <Level.Dir> <资源.spr>`

兼容格式的原始头字段及帧表诊断。只支持对应诊断布局，不保证所有 SPR 变体可读。

### `--legacy-spr-pixels <Level.Dir> <资源.spr>`

兼容格式的首帧像素索引统计，最多列出16项。只支持对应诊断布局，不替代完整解码或格式验证。

### `--export-land-debug <地图.dat> <输出目录>`

创建目录并写入/覆盖以下5张诊断 PNG：

- `terrain.png`
- `collision.png`
- `auxiliary.png`
- `preview.png`
- `terrain_collision_overlay.png`

这里的 `terrain.png` 使用**不透明背景**，不是可用于透明空洞往返编辑的导出图。需要编辑地形时使用 `--exportpng`。这些文件按顺序写入，不具备事务性。
