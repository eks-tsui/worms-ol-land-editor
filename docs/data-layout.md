# 地图数据目录

地图数据由使用者单独准备，不随源码仓库分发。操作前请备份整个待编辑地图的数据。

```text
MapWorkspace/
└── Data/
    ├── landNN.dat
    ├── Mfx/
    │   ├── Tmap01/Level.Dir
    │   └── TmapNN/Level.Dir
    └── Water/<名称>/Water.dir
```

编号范围为 1–999，格式为至少两位数字。例如 1 使用 `01`，100 使用 `100`。

## 输入依赖

1. 图形界面接受包含 `Data/Mfx` 的根目录，也接受其 `Data` 子目录。
2. 已有地图优先加载自己的 `Mfx/TmapNN/Level.Dir`。
3. 没有相应资源包时，使用显式选择目录内的 `Mfx/Tmap01/Level.Dir` 作为模板。
4. 模板必须拥有完整可解析的目录索引。不能用空文件或只含散装 PNG 的目录代替。
5. `Water` 资源用于水面预览；缺失时备用名称不代表资源可用。

默认模板没有开发机路径回退。当前 GUI 不提供任意新增/删除资源条目或从零构造 DIR 索引的功能。

## 输出与数据保护

- 保存生成 DAT 及其 `Level.Dir` 两个文件。
- 预先序列化和回读两个暂存文件，再备份待覆盖目标并逐个替换；普通 I/O 失败会尝试恢复。跨文件保存不是事务，进程中断、断电或恢复失败仍可能需要手工处理。
- 失败时若提示恢复目录，请先保留该目录和原始数据，不要盲目重复保存。
- 删除地图涉及 DAT 以及整个编号对应的 Tmap 目录。不要在该目录中保存其他唯一副本。
- 导出 PNG 仅包含地形，不包含出生点、资源包或地图选项。

## 素材与许可

源码不附带地图、水资源、模板或字体文件。只有在明确拥有再分发权时，才能将素材加入公开项目。添加新的样例前，应记录作者、来源和许可证，并保留相关声明。
